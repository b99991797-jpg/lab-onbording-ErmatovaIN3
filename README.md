# Аудит клиентского компьютера (Часть 2)

## 1. Категории базового ПО и почему они выбраны:
1. Офисный пакет (Office, LibreOffice, OpenOffice) — необходим для создания и редактирования документов.
2. Браузер (Chrome, Firefox, Yandex, Edge) — нужен для доступа к корпоративным порталам и интернету.
3. Архиватор (7-Zip, WinRAR, WinZip) — для работы с архивами и вложениями в электронной почте.
4. PDF-ридер (Adobe Acrobat, Foxit, SumatraPDF) — для чтения официальных документов и форм.
5. Антивирус (Kaspersky, ESET, Dr.Web, Defender) — для базовой защиты системы от угроз.

## 2. Признаки излишнего ПО (не относится к базовым офисным задачам):
- Игры и игровые платформы: Steam, Epic Games, Origin, Game, Gaming.
- Торрент-клиенты: uTorrent, BitTorrent, qBittorrent, Vuze (создают нагрузку на сеть).
- Мессенджеры: Discord, Telegram, WhatsApp, Viber, Skype (могут использоваться в личных целях).

## 3. Как проверялась работоспособность логики (Шаг 8 методички):
- Проверка раздела "Недостающее ПО": Я временно удалила из кода поиска архиватора слова "7-Zip" и "WinRAR", оставив только "WinZip". Скрипт успешно выдал рекомендацию: "[!] Archiver not found". После возврата слов в код он снова показал "[OK]".
- Проверка раздела "Излишнее ПО": Скрипт корректно нашел установленный на компьютере Steam и вывел его в раздел "SOFTWARE REQUIRING REVIEW". Торренты и мессенджеры не были найдены, скрипт вывел "Not found (good!)".

## 4. Ограничения решения:
- Скрипт проверяет только программы, установленные для всех пользователей (ветка реестра HKLM). Он не видит программы, установленные только для текущего пользователя.
- Браузер Edge присутствует в Windows 11 по умолчанию, поэтому его наличие не гарантирует, что рабочее место реально настроено пользователем.
- Скрипт выдает только рекомендации к проверке для администратора, а не прямые указания к удалению, так как некоторые программы могут быть нужны для специфических задач.
