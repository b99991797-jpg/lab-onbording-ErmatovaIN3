## 3. Критерии проверки (чек-лист)
### 3.1. Функциональная корректность
- [ ] Корзина корректно обновляет итоговую сумму при изменении количества товаров.
- [ ] Скидки применяются строго согласно бизнес-правилам, без отрицательных итоговых сумм.

### 3.2. Безопасность / Надежность
- [ ] Чувствительные данные (токены, данные карт) не выводятся в `console.log`.
- [ ] Реализована корректная обработка ошибок при недоступности бэкенд-API (показ сообщения об ошибке пользователю).

### 3.3. Производительность
- [ ] Компонент не вызывает лишних ре-рендеров при обновлении состояния (используются `React.memo`, `useMemo` или `useCallback`).

### 3.4. Читаемость и стиль
- [ ] Код соответствует стандартам TypeScript, переменные имеют понятные названия (нет `x`, `y`, `data1`).
